## What I've built

**Web Diagnostic** is a tool that checks any website's DNS, HTTP, redirects, SSL/TLS and timing, and gives back one JSON report. One Spring Boot backend powers both a website and a Chrome extension.

- [Live website](https://webinsight.duckdns.org/)
- [Chrome extension](https://chromewebstore.google.com/detail/web-diagnostic/lfomgibolicppnokhaphgkndjnahhddd) on the Chrome Web Store
- Code: [backend](https://github.com/Aadhil111/web-diagnostic-backend), [website](https://github.com/Aadhil111/web-diagnostic-website), [extension](https://github.com/Aadhil111/web-diagnostic-extension)

Since the backend makes requests to URLs that strangers type in, a lot of the work went into security: SSRF protection (port allow-list, private and cloud-metadata IP blocking, pinned IPs against DNS rebinding), rate limiting and strict CORS. HTTP and TLS checks run in parallel on Java 21 virtual threads. It runs in Docker on AWS EC2, behind Caddy for automatic HTTPS.
